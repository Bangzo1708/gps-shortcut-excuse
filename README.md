A one-line excuse, in the GPS's own voice, for sending the driver down the wrong road — written for make.fun's "The GPS Swears It Was a Shortcut" bounty. Running the program writes the single-line excuse (at most 200 characters, no setup, no dialogue tags) to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
